# Multi-Agent Quantitative Bipolar Argumentation

This repository provides a Python implementation and examples for multi-agent bipolar argumentation

This project extends Quantitative Bipolar Argumentation Frameworks (QBAFs) with:
- Multi-agent preferences and objectives
- Utterance rationality
- Utterance equilibrium
- Expansion/reduction dialogue protocols

Includes examples and experiments under:
- DF-QuAD semantics
- Quadratic Energy semantics

## Requirements

Install dependencies:

```bash
pip install matplotlib numpy pygraphviz
pip install "QBAF-Py[Visualizer] @ git+https://github.com/filipnaudot/Quantitative-Bipolar-Argumentation.git"
```
